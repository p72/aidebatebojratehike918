# Opus-A の作戦メモと出典（Opus-B には渡していない）

## 立場
日本の1人当たり名目GDP（ドル換算）が韓国に抜かれたのは、円安による見かけの面が大きく、豊かさの差は数字ほどではない（為替要因派）。

## データ（FRED API で 2026年10月14日に取得）
| 系列 | 値 |
|---|---|
| JPNNGDP（日本の名目GDP、10億円、年平均） | 2012年 505,529.7、2025年 666,436.6（+31.8%） |
| DEXJPUS（円／ドル） | 2012年平均 79.82、2025年平均 149.57、2026年10月9日 158.34 |
| DEXKOUS（ウォン／ドル） | 2012年平均 1,126.16、2025年平均 1,421.40、2026年10月9日 1,342.13 |

計算：名目GDPのドル換算は、2012年 505.5兆円÷79.82＝約6.33兆ドル、2025年 666.4兆円÷149.57＝約4.46兆ドル（約-30%）。ウォンの対ドル下落は 1,126→1,342 で約16%。

## 報道
- 内閣府（2025年12月23日）：2024年の日本の1人当たりGDPは33,785ドル、OECD38か国中24位、韓国より3つ下。（[朝鮮日報](https://www.chosunonline.com/site/data/html_dir/2025/12/26/2025122680063.html)）
- 2023年に韓国（35,563ドル）が日本を逆転。比較可能な1980年以降で初。（[日本経済新聞](https://www.nikkei.com/article/DGXZQOUA2338M0T21C24A2000000/)）
- IMF（2026年10月13日の世界経済見通し）：2026年の1人当たり名目GDPは韓国約43,511ドル、日本約35,400ドル。4月時点の見通しでは韓国37,412ドル、日本35,703ドル。（[亜洲経済](https://japan.ajunews.com/view/20261014145258643)。検索結果の抜粋で確認）
- ウォンは6月末1,549.4ウォン→9月4日1,350.4ウォン（約13%のウォン高）。半導体企業のドル供給が主因。2026年6月の輸出は約1,022億ドルで単月初の1,000億ドル超。（検索結果の抜粋。[第一生命経済研究所](https://www.dlri.co.jp/files/macro/654527.pdf) ほか）
- 対外純資産：2025年末 561兆7,504億円、8年連続増加、国別3位。経常収支は2025年 32兆2,350億円。（[財務省](https://www.mof.go.jp/policy/international_policy/reference/iip/data/2025_g.htm)）
